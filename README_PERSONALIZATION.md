## 💡 ПРИМЕРЫ

### Генерация с плохой восстановлением:
```bash
POST /api/v1/workouts/generate
{
  "sleepHours": 4,
  "sleepQuality": 3,
  "stressLevel": 9
}

→ Вес: база × 0.95 (RPE) × 0.8 (сон) × 0.9 (стресс) = -32%
```

### Логирование с RPE:
```bash
POST /api/v1/workouts/complete
{
  "exercises": [{
    "rpe": 8,
    "sets": [{"rpe": 9}]
  }]
}

→ На следующей тренировке: вес -5% (из-за высокого RPE)
```

## 🎯 ИТОГОВЫЙ РЕЗУЛЬТАТ

Пользователь видит:
- **Перед тренировкой:** "Ты плохо спал - сниженая интенсивность на 20%"
- **Во время:** Система просит оценить сложность (RPE)
- **После:** Система просит оценить технику
- **След. тренировка:** Веса автоматически адаптированы под его результаты
